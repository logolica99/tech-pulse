Microsoft AI used its Ignite conference on 17 November to release seven new models from its in-house MAI family. Price is the selling point: Microsoft says customers want models cheap enough to keep agents running around the clock on real engineering work.

## The lineup

All comparisons below are Microsoft's own figures.

- **MAI Code 2** targets everyday enterprise coding. Averaged across four coding benchmarks, Microsoft says it gets 98% of GPT-6.1 Sol's performance at about 40% of the price, and 96% of Claude Opus 5.5's at about 5% of the price. It is available in GitHub Copilot. Microsoft says it is not yet tuned for harder work like fundamental science research or very long-horizon agent tasks.
- **MAI Code 2 Flash** is a cheaper model for routine edits, fixes and explanations. It is in GitHub Copilot and in limited preview in Microsoft Foundry.
- **MAI Cyber 2 Flash** is a security model. Microsoft says it matches GPT-6 Astra on the CyberGymE2E benchmark at under 2% of the cost per task, with output tokens priced 86% lower than its predecessor.
- **MAI Image 2.7** ranks first on Artificial Analysis for image editing, according to Microsoft. A Flash variant costs about $10 per 1,000 images.
- **MAI Realtime 1** is Microsoft's first live speech-to-speech model, starting at $0.01 per audio minute.
- **Dragon Copilot Transcribe**, built on MAI Transcribe 2, now handles all doctor–patient transcription in Dragon Copilot. Microsoft says that comes to about 10 million encounters a month.
- **Decision 1.1** is a routing model that sends requests to bigger, pricier models only when needed. Microsoft says 4,000 customers use it.

Microsoft also says Maia 200, its second-generation AI accelerator, is now in production running its largest models, with 1.7 times more tokens per watt.

## Licensed weights

Microsoft also introduced MAI Licensed Weights. Organizations can take an MAI model, customize it with their own data and run it in their own Azure environment, with control over who can access it. Microsoft says customer data and adaptations stay with the customer, and it will only use them to train its own models with the customer's express agreement.
