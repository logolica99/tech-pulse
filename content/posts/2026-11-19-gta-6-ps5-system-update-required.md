**Short answer: update your PS5's system software.** Sony says GTA 6 needs the latest PS5 system software, version 26.07-14.23.00, before it will play. If your console is on an older version, install the update and the game should launch. This is separate from the GTA 6 download and from Rockstar's own game patches, so a full pre-load does not cover it.

## What Sony said

On November 18, the PlayStation Support US account on X posted: "Sony Interactive has issued a PS5 system software update that is required before playing Grand Theft Auto VI." It asked players to install it before midnight on November 19 so they were ready on launch day. Push Square and Engadget both quoted the post.

Sony's PS5 system software page lists 26.07-14.23.00 as the current version. PlayStationInfo notes it applies to both the standard PS5 and PS5 Pro. The release notes say only: "We've made some security fixes to the system software." Engadget, citing IGN, puts the download at 1.267GB.

## How to install it

1. From the PS5 home screen, go to **Settings > System > System Software > System Software Update and Settings**.
2. The console shows whether a new version is available. If it is, start the download there and let it install.
3. To avoid this next time, turn on **Download Update Files Automatically** and **Install Update Files Automatically** on the same screen, as Sony's GTA VI support page recommends.

If the game still will not start, Sony's GTA VI support page says PlayStation Support handles game launch and download problems, while Rockstar Support handles gameplay issues, patches and bugs.

## Why is it required?

Sony has not said. Push Square calls a mandatory update on launch day "unprecedented." Engadget, citing IGN, notes the update arrived a day after a well-known PS5 jailbreaker claimed to have copied a game's data on the previous firmware, 14.22, and suggests 14.23 may close that hole. That is a theory, not Sony's explanation.

## Official or not?

- **Official (Sony):** the update is required for GTA 6, the version number 26.07-14.23.00, the "security fixes" note, and the menu steps.
- **Reported:** the 1.267GB size comes from IGN via Engadget. The link to PS5 jailbreaks is speculation by IGN and Engadget; Sony has given no reason beyond security.
